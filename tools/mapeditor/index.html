Blood Map Maker

Makes simple levels for NotBlood Chosen (and other Blood ports that read Blood's .MAP files): rooms, heights, sky, player starts, weapons and items.

  1. ▭ Room: tap two corners. ✎ Shape: tap the corners one by one, then tap the first corner again (or Finish).
  2. Draw rooms touching each other to join them: where their edges meet you can walk through. Rooms can't overlap.
  3. Select a room to set its floor height, ceiling height, textures, light and sky. A small floor difference is a step, a big one needs a jump.
  4. 3D / Walk: look at the map from above, or walk through it from the single player start to try steps, openings and heights (sizes are close to Blood's, not exact).
  5. Doors, lifts, secrets: select a room and change This is. A door is a thin room between two rooms; a lift raises its floor; a secret room counts as a secret when the player walks in.
  6. Real textures: ☰ → Blood files for textures and pick TILES000–017.ART and BLOOD.RFF from your game folder. They stay on your device.
  7. + Thing: pick what to place (starts, weapons, ammo, health, armor, power-ups, keys, enemies) and tap in a room. Select a start to turn it.
  8. A map needs a single player start. Bloodbath uses the bloodbath starts (put 8, one per player); co-op uses one single player start per player.
  9. ☰ → Save .MAP for the game. Put the file in the game folder (Android: the NotBlood folder of the main storage) and pick it under < USER MAP > when you choose an episode, or MULTIPLAYER → USER MAP. In online games the others get the map from the server by themselves.

Textures are tile numbers from Blood's TILES*.ART (the lists show the ones Blood's levels use most). Moving with two fingers works in every tool; pinch to zoom. Your map is kept in this browser while you work; save the project file to keep it for good.
