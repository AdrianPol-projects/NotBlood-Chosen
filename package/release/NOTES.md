Ready-to-play builds of **NotBlood Chosen**: NotBlood with co-op saves, online lobbies, a live game dashboard, a MODS menu and a LAN game finder.

| Download | For |
| --- | --- |
| `...-win64.zip` | Windows 10/11 (64-bit) |
| `...-linux-x64.zip` | Linux (x86_64, needs SDL2) |
| `...-macos.zip` | macOS 11 or newer, Apple Silicon and Intel |
| `...-android.apk` | Android 5 or newer (phones, tablets, Chromebooks) |

Unzip, copy your Blood files into the `NotBlood` folder and start the game. On Android install the APK, start it once and allow it "access to all files": it then uses the folder `NotBlood` in the main storage (next to `Download`) - copy your Blood files there. The README in the zip explains the rest (movies, add-ons, mods, co-op saves, online play, macOS without an administrator).

Every player in a network game needs the same version. The iPad version is built in [NotBlood-iOS](https://github.com/AdrianPol-projects/NotBlood-iOS).
