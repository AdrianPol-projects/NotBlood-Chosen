# Blood Extra Crispy in NotBlood Chosen (Android test build)

A test of the *Blood Extra Crispy* mod (by VGames, for Nightdive's Refreshed Supply) as a mod for NotBlood Chosen. The normal release is [v1.2](https://github.com/AdrianPol-projects/NotBlood-Chosen/releases/latest); this build is only for trying the mod.

**The app:** it's called *NotBlood Crispy* and installs next to NotBlood instead of replacing it. Both use the same `NotBlood` folder on the phone, so your Blood files, settings and saves are shared.

**Setup:**
1. Install the APK. If you have never used NotBlood on this phone, copy your Blood files into the `NotBlood` folder first (see the [v1.2 notes](https://github.com/AdrianPol-projects/NotBlood-Chosen/releases/latest)).
2. Download **Blood Extra Crispy v1.2** from ModDB (`BEC_v1.2_RS.zip`) and unpack it.
3. Copy its `BEC_1.2` folder, unchanged, into `NotBlood/mods/` on the phone. The result is `NotBlood/mods/BEC_1.2/EXTRAC.RFF` and so on.
4. Start NotBlood Crispy, go to **MODS**, choose **BLOOD EXTRA CRISPY**. The game restarts with the mod.

**What you get:**
- The mod's look: its title and menu background, and its edited sprites.
- Its sounds.
- **Gory Kills:** walk up to a nearly dead enemy, face it and press **USE** (OK/use button). Caleb finishes it in first person, heals a little, and kicks the body away. They work on cultists (all four), axe zombies, fat zombies, flesh gargoyles, gill beasts, innocents, hell hounds and phantasms. The enemy must be badly hurt (below about 12 health), except innocents. Single player only.

**Not included (yet):** the mod's new weapons, enemies, maps and scripts. Those are made for the remaster's engine.

To play the normal game again: MODS > ORIGINAL GAME.

Nothing of the mod is in this download. It only reads the mod files you put in `mods/BEC_1.2`.
